# 验证记录

本地环境：Windows、Node.js 22.17.0、Microsoft Edge、Playwright 1.64.1。

```powershell
npm ci
npm run test:all
```

Windows 默认使用已安装的 Edge。其他系统使用 Chromium，先执行 `npx playwright install chromium`。可通过 PLAYWRIGHT_CHANNEL 指定浏览器通道。

7 项接口集成测试覆盖：17 件商品与图片、库存和数量校验、真实 SQLite 持久化、加密地址、价格防篡改、购物车变更冲突、直接购买、访客隔离、并发库存、防重复订单、CSRF、静态目录访问边界与数据删除。

4 组浏览器端到端测试覆盖：

1. 桌面官网进入商店、分类收藏、尺码数量、刷新、地址校验、模拟付款、待收货订单、重启服务后恢复、不同访客隔离。
2. 手机菜单进入商店、英文切换、直接购买保留购物车、地址回填、删除商品及访客数据。
3. 真实订单提交成功但响应丢失，重试后仍只有一笔订单、只扣一次库存。
4. 后端不可用时显示错误并禁止结算，恢复后重新连接。

测试启动真实 HTTP 服务和独立的临时 SQLite 文件，不修改开发数据库。网络中断测试仅拦截故障请求，成功订单由真实后端创建。全部 11 项已通过；截图与报告在 test-results 和 playwright-report 中生成，这些目录不提交 Git。

验证范围是本地网站服务，不包括公网部署、真实支付、物流、HarmonyOS 原生端或真实人脸认证。公网部署后还需验证 HTTPS、反向代理、持久磁盘和重启策略。
